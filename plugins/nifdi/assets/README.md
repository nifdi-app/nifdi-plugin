# Listing artwork

## Full wordmark

`logo.svg` is the existing square wordmark used for nifdi's WorkOS branding:
<https://workos.imgix.net/app-branding/environment_01JSPREC9QBRC66SA4TGGXK1EE/01KJJ100SHQDCKM22MT2AT2XKH>.
The original SVG is preserved unchanged, including the positioning of the wordmark
inside its 160 × 160 white square. It was retrieved on 26 October 2026.

`logo.png` is a 1024 × 1024 raster export of that SVG. OpenAI's `logo` field and
Claude's listing `icon` field use it.

## Compact mark

`icon.svg` is the existing nifdi app mark from <https://nifdi.app/favicon.svg>, also
stored in the nifdi-app repository at `public/favicon.svg`. The source was checked
against the hosted file on 26 October 2026. It is the white nifdi “n” on a black square.

`icon.png` is a 1024 × 1024 raster export of that SVG, used for OpenAI's small
`composerIcon`.

Both plugins contain the same artwork. Update both copies together. The artwork
remains a nifdi trademark; the repository licence grants no trademark rights.
